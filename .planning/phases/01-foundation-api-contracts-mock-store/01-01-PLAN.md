# Plan 01-01: Backend API Contracts & Checkout Routers

## Objective
Implement the agreed-upon API contracts for checkout session initiation, dialogue turns, decision submissions, and user state querying using FastAPI and Pydantic models.

## Tasks

### 1. Define Pydantic Schemas (`backend/app/schemas/checkout.py`)
- `CartItem`: `name: str`, `price: float`, `qty: int`
- `CartData`: `store: str`, `items: list[CartItem]`, `total: float`
- `CheckoutStartRequest`: `user_id: str | None = None`, `cart: CartData`
- `CheckoutStartResponse`: `session_id: str`, `opening_line: str`, `voice_link: str | None = None`
- `CheckoutTurnRequest`: `session_id: str`, `user_text: str`
- `CheckoutTurnResponse`: `reply_text: str`, `reply_audio_url: str | None = None`, `done: bool`
- `CheckoutDecisionRequest`: `session_id: str`, `decision: Literal["buy", "save", "skip"]`
- `CheckoutDecisionResponse`: `acorns_awarded: int`, `status: str`, `total_earned: int`, `balance: int`, `tier: str`, `tier_up: bool`
- `UserStateResponse`: `total_earned: int`, `balance: int`, `tier: str`, `next_tier_at: int | None`, `streak: int`, `recent_decisions: list[dict]`

### 2. Implement Checkout Router (`backend/app/routers/checkout.py`)
- `POST /checkout/start`: creates session, stores cart, generates simulated opening line (e.g. *"Ooh, $89 headphones! What are they for?"*).
- `POST /checkout/turn`: tracks turn count (max 3), generates replies, marks `done: true` when appropriate.
- `POST /checkout/decision`: evaluates decision, computes acorns via rewards engine, updates user stats, and flags `tier_up`.

### 3. Implement User State Router (`backend/app/routers/user_state.py`)
- `GET /user/state`: queries current user stats, tier progress, and recent decision history.
- `POST /user/seed`: endpoint to seed demo accounts (e.g., set `total_earned = 980` for live evolution demo).

### 4. Register Routers in `backend/app/main.py`
- Wire `checkout.router` and `user_state.router` into the FastAPI application with appropriate tags and prefixes.

## Verification
- Test all endpoints with `curl` or automated python tests (`pytest` / `httpx`).
- Verify OpenAPI spec at `/docs` matches the schema contract in `squirrel-savings-design-doc.md`.
