# Plan 01-03: Mock Shopping Store & Checkout Page

## Objective
Build a modern, interactive mock shopping store with product cards, cart drawer, and a realistic checkout page to serve as the testbench for the extension and voice agent.

## Tasks

### 1. Store Product Catalog (`demo/store/index.html`, `demo/store/products.js`, `demo/store/store.css`)
- Clean, premium eCommerce design ("Acorn Outfitters" or "DubHacks Marketplace").
- Products:
  - *"EchoPulse Sport Headphones"* — $89.00
  - *"CloudKnit Heavyweight Hoodie"* — $65.00
  - *"AeroStride Marathon Sneakers"* — $120.00
  - *"Thermal Hydro Flask 32oz"* — $38.00
- Features:
  - Interactive "Add to Cart" buttons.
  - Slide-out cart drawer showing selected items, quantity increments, subtotal, and tax.
  - "Proceed to Checkout" button linking to `checkout.html`.

### 2. Mock Checkout Page (`demo/store/checkout.html`)
- Realistic checkout layout:
  - Left column: Customer info, shipping address, fake payment method (credit card inputs).
  - Right column: Cart summary (`#order-summary`) listing items (`.order-item`), price tags, and total (`#order-total`).
  - Semantic markup and `data-checkout-stage="ready"` attribute for easy content-script targeting.
  - Final "Place Order" button.

### 3. Static Server & Dev Workflow
- Serve `demo/store/` easily via Vite or Python HTTP server:
  - Add script to `package.json` or mount as static directory in FastAPI under `/demo`.

## Verification
- Load `demo/store/index.html` in browser.
- Add items to cart and navigate to checkout.
- Verify checkout page displays items and total in the DOM as expected for content-script consumption.
