# Plan 01-02: Acorn Rewards Engine & State Persistence

## Objective
Implement the business rules for calculating acorn rewards, maintaining user streaks, computing tier thresholds, and persisting user and decision data.

## Tasks

### 1. Rewards & Tier Calculator (`backend/app/core/rewards.py`)
- Define tier constants:
  - `Baby` (0)
  - `Scout` (250)
  - `Forager` (1,000)
  - `Hoarder` (3,000)
  - `Golden` (7,500)
- Function `get_tier_info(total_earned: int) -> tuple[str, int | None]`: returns `(current_tier, next_tier_at)`.
- Function `calculate_decision_reward(decision: str, cart_total: float, recent_decisions: list[str]) -> tuple[int, str, bool]`:
  - Calculate base acorns:
    - `"skip"`: `40 + min(int(cart_total // 2), 110)` (max 150)
    - `"save"`: `30`
    - `"buy"`: `20`
  - Streak check: +25 if the last 2 decisions prior to this were also non-buy decisions ("save" or "skip").
  - Daily cap check: ensure user has not exceeded 300 acorns in 24 hours.

### 2. State Storage Provider (`backend/app/core/storage.py`)
- In-memory / SQLite backing store:
  - User records: `id`, `total_earned`, `balance`, `tier`, `streak`, `created_at`.
  - Decision records: `id`, `user_id`, `store`, `items`, `cart_total`, `decision`, `acorns`, `status`, `created_at`.
- Provide atomic updates: when a decision is registered, update `total_earned`, `balance`, check for tier upgrade, and append to decision log.

### 3. Unit Tests (`backend/tests/test_rewards.py`)
- Test skip calculation on $10 cart (40 + 5 = 45 acorns).
- Test skip calculation on $300 cart (capped at 150 acorns).
- Test buy flat 20 acorns.
- Test save flat 30 acorns.
- Test tier transition from 980 XP to 1,005 XP triggering `tier_up = True` into `Forager`.
- Test daily cap clamp.

## Verification
- Run tests via `pytest` to guarantee deterministic and edge-case-proof acorn calculations.
