# Plan 02-03: In-Page Overlay "Pip's Swaps" UI, Click Tracking & Acorn Rewards

## Objective
Render a compact, high-converting "Pip's Swaps" card list inside the Shadow DOM checkout overlay, handle safe new-tab navigation to the alternative product search URLs, log click events, and award acorns to the user for exploring savings.

## Tasks

### 1. Build "Pip's Swaps" Card UI Component (`extension/src/ui/components.js` & `extension/src/content/index.js`)
- Add `pipsSwapsCard(recommendations)`:
  - Header: `✨ Pip's Swaps` with badge `Save up to $X`.
  - List of 2–3 recommendation cards:
    - **Product Title**: Clean, bold title with external link icon.
    - **Price & Savings Pill**: e.g., `$49.99` with green badge `Save $35.00`.
    - **Pip's Advice**: Cheeky squirrel reason (e.g., *"Refurbished model with 1-yr warranty—same sound, keeps $35 in your pocket!"*).
    - **Action Button**: `"Check Deal"` button pointing to `search_url`.

### 2. Style Component in Shadow DOM (`extension/src/content/overlay.css`)
- Style cards with warm border, subtle hover elevation, green savings highlights (`#2d5a27`, `#d8f3dc`), and responsive scrolling within the overlay.
- Keep overlay compact so it never obscures critical checkout fields or feels intrusive.

### 3. Click Tracking & Acorn Reward Logic
- Add event delegation in `overlay` root for `[data-action="view-swap"]`:
  - Opens `search_url` via `window.open(url, "_blank")`.
  - Calls `applySwapBonus(userId, swapId)` via `extension/src/lib/progress.js` to award +10 acorns for considering alternatives.
  - Shows celebratory toast: `+10 acorns for exploring a smart swap! 🌰`.

### 4. Integration into Content Script Overlay Lifecycle
- Embed `pipsSwapsCard` directly into `panelHtml(checkout, status)` right below the cart summary.
- If recommendations are loading, render a subtle skeleton/shimmer placeholder.
- If no recommendations found or error, seamlessly omit the section without breaking the main overlay.

## Verification
- Load mock store checkout on `http://localhost:8000/demo/`.
- Verify the in-page overlay renders "Pip's Swaps" cards with accurate savings badges.
- Click "Check Deal": confirm it opens the deterministic Google/Amazon search URL in a new tab, awards +10 acorns, and updates the user's acorn balance chip.
