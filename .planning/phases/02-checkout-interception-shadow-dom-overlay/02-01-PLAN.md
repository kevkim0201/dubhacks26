# Plan 02-01: TypeSafe Jev Recommender Engine & Backend Route

## Objective
Implement a TypeSafe Jev-powered product recommendation pipeline in FastAPI that accepts scraped cart data and returns 2–3 cheaper or higher-value alternative products with deterministic, non-hallucinated search links.

## Tasks

### 1. Define Typed Schemas (`backend/app/schemas/recommendations.py` or within router)
- `CartItemInput`: `name: str`, `price: float | None = None`, `quantity: int = 1`
- `RecommendationsRequest`:
  - `items: list[CartItemInput] | list[str]` (handles both structured items and raw item strings)
  - `total_cost: float`
  - `store_domain: str`
- `ProductRecommendation`:
  - `id: str`
  - `title: str`
  - `estimated_price: float`
  - `estimated_savings: float`
  - `pip_reason: str`
  - `search_query: str`
  - `search_url: str` (Deterministic URL built from `search_query`: `https://www.google.com/search?tbm=shop&q=...` or Amazon search URL)
- `RecommendationsResponse`:
  - `recommendations: list[ProductRecommendation]`
  - `summary: str`

### 2. Implement Jev Recommender Service (`backend/app/services/jev_recommender.py`)
- Define deterministic search query generator function:
  - Generates clean search queries (e.g. `"budget mechanical keyboard hot swappable"`, `"refurbished over-ear noise cancelling headphones"`).
  - Builds verified query URLs: `https://www.google.com/search?tbm=shop&q={url_encoded_query}`.
- Decision pipeline:
  - Identifies core product category from items (e.g., Electronics, Footwear, Apparel, Accessories).
  - Uses Gemini (`gemini-2.5-flash` or heuristic category matrix fallback) to generate smart alternatives:
    - Budget Alternative (30–50% cheaper, high rating).
    - Refurbished / Open-Box Alternative (high savings, sustainable).
    - Long-Term Value Alternative (durable alternative preventing re-buys).
  - Formulates Pip's cheeky, supportive reason (`pip_reason`).

### 3. Create Recommendations Router (`backend/app/routers/recommendations.py`)
- Route: `POST /api/checkout/recommendations`
- Authenticated with `user: AuthUser` dependency from `app.core.auth` (with graceful fallback if unauthenticated demo user).
- Invokes `jev_recommender.get_recommendations(...)` and returns typed `RecommendationsResponse`.

### 4. Register Router in `backend/app/main.py`
- Import `from app.routers import recommendations`
- Mount via `app.include_router(recommendations.router)`

## Verification
- Run `pytest` or `curl` test against `POST /api/checkout/recommendations` with sample cart:
  ```json
  {
    "items": [{"name": "Pro Over-Ear Wireless Headphones", "price": 149.99}],
    "total_cost": 149.99,
    "store_domain": "bestbuy.com"
  }
  ```
- Confirm output returns 2–3 items with valid `estimated_savings > 0` and properly encoded `search_url`.
